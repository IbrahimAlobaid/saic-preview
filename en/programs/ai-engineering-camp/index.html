AI Engineering Camp

HANDS-ON · 10 SESSIONS · 30 HOURS

From understanding AI models to building demo-ready, deployable AI products.

10training sessions
30hours of training
8expert trainers
Capstoneteam graduation project

An advanced, hands-on training camp for final-year students and graduates of technical majors. It combines model building, AI systems engineering, teamwork, and the development of a final project. Its goal is to take participants from academic knowledge and isolated experiments in Jupyter Notebooks to building complete solutions with practical value, using ways of working close to real product development environments.

Camp methodology

  • Understand
  • →
  • Apply
  • →
  • Build the project

Prerequisites

The camp is not for complete beginners. Familiarity with Python, programming basics and machine learning concepts is recommended, along with the ability to learn and practice independently between sessions.

Who it is for

  • Final-year students in informatics engineering, telecommunications engineering and related majors.
  • Graduates aiming to work in AI engineering.
  • Developers who know Python and ML/DL basics and want to move on to building practical systems and products.

Capstone Project

The core idea

Participants work in teams to build a runnable, demo-ready AI product that addresses a clear problem and demonstrates design, implementation, evaluation and documentation skills.

Suggested project ideas

  • A source-cited research assistant
  • A RAG-based study assistant
  • A data extraction system for Arabic documents
  • A voice-based English learning assistant
  • A computer vision application

Design principle

RAG, agents or voice AI are not required in every project. The architecture must start from the needs of the problem, not from a wish to stack as many technologies as possible.

Project milestones

  1. End of session 06Form teams, pick a problem, and submit a short proposal.
  2. Session 07Design the solution and start development with AI coding tools.
  3. Session 08Integrate AI capabilities, tools or agents where needed.
  4. Session 09Finish integration and experiments; add voice or multimodal input if it suits the project.
  5. Session 10 · Demo DayTesting, the final demo, and a discussion of the engineering decisions.

Learning by building and reviewing, as in real work environments.

Typical structure of a 3-hour session

  • 15 min · Review

Final project evaluation criteria

  • Idea
  • Implementation

  • Documentation
  • Presentation

Outcomes and hiring

By the end of the camp, participants are expected to be able to

  • Choose the right model or technical approach for a problem, then train and evaluate it.
  • Turn models into services and applications using APIs and user interfaces.
  • Build applications based on LLMs, RAG and AI agents.
  • Use AI-assisted coding tools effectively and responsibly, with code review and testing.
  • Collaborate using Git, GitHub and Pull Requests.
  • Apply the basics of deployment, monitoring, evaluation and security.
  • Deliver a documented, runnable technical project that strengthens their professional profile.

Expected deliverables

  1. 1A GitHub repository with the assignments and practical applications.
  2. 2Hands-on experience building models and turning them into services.
  3. 3Practical applications in RAG, agents and voice AI.
  4. 4Experience writing requirements, using coding agents, and reviewing their output.
  5. 5A documented capstone project with setup instructions, evaluation results and a demo.
  6. 6Technical material to showcase in a GitHub portfolio and on LinkedIn.
