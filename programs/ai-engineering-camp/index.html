Capstoneمشروع تخرج جماعي

معسكر تدريبي تطبيقي متقدم يستهدف طلاب السنوات الأخيرة والخريجين من التخصصات التقنية، ويجمع بين بناء النماذج، وهندسة أنظمة الذكاء الاصطناعي، والعمل الجماعي، وتطوير مشروع نهائي. هدفه تأهيل المشاركين للانتقال من المعرفة الأكاديمية والتجارب المنفصلة داخل Jupyter Notebooks إلى بناء حلول متكاملة ذات قيمة عملية، وفق أساليب عمل قريبة من بيئات تطوير المنتجات الحقيقية.

المتطلبات السابقة

المعسكر ليس مخصصًا للمبتدئين تمامًا. يُفضّل الإلمام بأساسيات Python والبرمجة ومفاهيم تعلم الآلة، مع القدرة على التعلم والتطبيق الذاتي بين الجلسات.

الفئة المستهدفة

  • طلاب السنوات الأخيرة في الهندسة المعلوماتية، وهندسة الاتصالات، والتخصصات القريبة.
  • الخريجون الساعون إلى العمل في مجال AI Engineering.
  • المطورون الذين يعرفون أساسيات Python وML/DL ويريدون الانتقال إلى بناء أنظمة ومنتجات عملية.

الجلسات العشر

#الجلسةأبرز المخرجات العملية
01Git, GitHub & AI Engineer Workflowتجهيز بيئة العمل، إدارة الفروع، إنشاء أول Pull Request وحل تعارض دمج.
02Machine Learning: Fundamentals → Productنموذج تنبؤ متكامل مع FastAPI وStreamlit وDocker.
03Deep Learning: From Scratch → PyTorchشبكة عصبية من الصفر، وتطبيق PyTorch مع منحنيات تدريب وتحليل أداء.
04Computer Vision: Classical → Detection & Trackingنموذج تصنيف صور وتجربة عملية لكشف الأجسام وتتبعها في الفيديو.
05NLP & Transformersتخصيص نموذج BERT لمهمة استخراج الكيانات المسماة (NER) وتقييمه.
06LLM Engineering: APIs, Prompting & RAGمساعد RAG يعمل على وثائق المعسكر مع واجهة مستخدم.
07AI-Assisted Coding: Copilot, Claude Code & Codexتطوير ميزة برمجية بمساعدة Agent وتقديم PR مع مراجعة واختبارات.
08Agentic AI: Tools, MCP & Multi-Agent Systemsوكيل يستخدم أدوات وMCP Server مع سجلات تتبع للنجاح والفشل.
09Voice & Multimodal Agents with Pipecatمساعد صوتي تفاعلي، مع تجربة إدخال مرئي عند الإمكان.
10Production, Evaluation & Demo Dayأساسيات CI/CD والنشر والمراقبة، ثم عرض المشاريع النهائية.

مشروع التخرج · Capstone Project

الفكرة الأساسية

يعمل المشاركون ضمن فرق لبناء منتج AI قابل للتشغيل والعرض، يخدم مشكلة واضحة ويُظهر مهارات التصميم والتنفيذ والتقييم والتوثيق.

أمثلة مقترحة للمشاريع

  • مساعد بحث علمي موثق بالمصادر
  • مساعد دراسي يعتمد على RAG
  • نظام لاستخراج البيانات من الوثائق العربية
  • مساعد لتعلم الإنجليزية بالصوت
  • تطبيق للرؤية الحاسوبية

مبدأ التصميم

لا يلزم استخدام RAG أو Agents أو Voice AI في كل مشروع؛ يجب أن تنطلق المعمارية من احتياجات المشكلة لا من الرغبة في جمع أكبر عدد من التقنيات.

محطات المشروع

  1. نهاية الجلسة ٠٦تشكيل الفرق، اختيار المشكلة، وتقديم مقترح مختصر.
  2. الجلسة ٠٧تصميم الحل وبدء التطوير باستخدام أدوات AI Coding.
  3. الجلسة ٠٨دمج قدرات AI أو الأدوات والوكلاء عند الحاجة.
  4. الجلسة ٠٩استكمال التكامل والتجارب، وإضافة الصوت/الوسائط إذا كانت مناسبة للمشروع.
  5. الجلسة ١٠ · Demo Dayالاختبار والعرض النهائي ومناقشة القرارات الهندسية.

المخرجات والتوظيف

بنهاية المعسكر، يُتوقع أن يتمكن الطالب من

  • اختيار النموذج أو الأسلوب التقني المناسب للمشكلة، وتدريبه وتقييمه.
  • تحويل النماذج إلى خدمات وتطبيقات باستخدام APIs وواجهات مستخدم.
  • بناء تطبيقات قائمة على LLMs وRAG وAI Agents.
  • توظيف أدوات AI-Assisted Coding بفاعلية ومسؤولية، مع مراجعة الشيفرة واختبارها.
  • التعاون باستخدام Git وGitHub وPull Requests.
  • تطبيق أساسيات النشر والمراقبة والتقييم والأمان.
  • تقديم مشروع تقني موثق وقابل للتشغيل، يدعم الملف المهني للمشارك.

المخرجات المتوقعة

  1. ١مستودع GitHub يحتوي الواجبات والتطبيقات العملية.
  2. ٢خبرة تطبيقية في بناء النماذج وتحويلها إلى خدمات.
  3. ٣تطبيقات عملية في RAG وAgents وVoice AI.
  4. ٤خبرة في كتابة المتطلبات، واستخدام Coding Agents، ومراجعة نواتجها.
  5. ٥مشروع Capstone موثق، مع طريقة تشغيل ونتائج تقييم وعرض تجريبي.
  6. ٦مادة تقنية يمكن عرضها في GitHub Portfolio وLinkedIn.
